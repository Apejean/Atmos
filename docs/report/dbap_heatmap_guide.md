# DBAP 기반 3D 음압 히트맵 구현 가이드 (@Front, @Back 에이전트 용)

## 개요
공간 음향 시뮬레이터에서 스피커 배치에 따른 소리의 분포(Sweet Spot)를 시각화하기 위해 DBAP (Distance-Based Amplitude Panning) 알고리즘을 기반으로 한 실시간 히트맵 렌더링을 구현합니다.
**주의**: 히트맵은 정적 이미지 에셋이 아닙니다. 스피커의 위치(X,Y,Z)와 룸 크기가 변할 때마다 실시간으로 연산되어야 합니다.

## 1. 수학적 음압 계산 로직 (@Back 담당)
방 안의 임의의 측정 포인트 `P(x, y, z)`에서 느껴지는 총 음압(Intensity)을 계산하는 함수를 작성해야 합니다.

*   **거리 계산**: 포인트 `P`와 각 스피커 `S_i(x, y, z)` 사이의 유클리드 거리 `d_i`를 구합니다.
*   **감쇠(Rolloff) 적용**: 거리에 따른 신호 감쇠 법칙(Inverse Square Law 등)을 적용합니다. DBAP의 기본 공식에 따라 음압 비중을 계산합니다.
    *   `Weight_i = 1 / (d_i ^ a + ϵ)` (a는 롤오프 계수, ϵ는 0으로 나누는 것을 방지하는 아주 작은 값)
*   **총 음압**: 모든 스피커에서 오는 Weight를 합산하고, 시각화를 위해 0.0 ~ 1.0 사이의 값으로 정규화(Normalize)하여 배열(Grid Matrix) 형태로 반환합니다.

## 2. 렌더링 및 UI 연동 (@Front 담당)
계산된 음압 Matrix 데이터를 화면(바닥 격자)에 부드러운 그라데이션 색상으로 칠해야 합니다.

*   **렌더링 기법**: 
    1.  *옵션 A (추천/고성능)*: Flutter의 **Fragment Shader (`FragmentProgram`)**를 사용하여 GPU 레벨에서 픽셀 단위로 거리를 계산하고 색상을 보간(Interpolation)합니다.
    2.  *옵션 B (CustomPaint)*: 바닥을 촘촘한 그리드로 나누고, 각 꼭짓점의 음압 데이터를 바탕으로 `ui.Gradient` 나 `Path` 단위의 색상 채우기를 진행합니다.
*   **컬러 매핑 (Color Map)**:
    *   Intensity `1.0` (가장 강함, 스피커 근처 / 스윗스팟 결합부) -> **Red (붉은색) / 높은 불투명도**
    *   Intensity `0.5` (중간) -> **Yellow / Green (노란색/녹색)**
    *   Intensity `0.1 이하` (약함) -> **Blue / Dark Blue (푸른색) / 완전 투명**
*   **3D 회전 동기화 (가장 중요)**:
    *   히트맵 역시 평면 이미지가 아닙니다. `dynamic_3d_room_guide.md`에서 구현한 **룸 와이어프레임과 동일한 `Matrix4` 회전/투영 로직**을 적용받아야 합니다.
    *   사용자가 화면을 돌릴 때 히트맵도 바닥에 찰착 붙어서 같이 돌아가야 3D 공간감이 유지됩니다.

## 3. 최적화 (Optimization)
*   스피커를 드래그해서 위치를 옮기는 도중(실시간)에는 히트맵 해상도(연산량)를 낮추어 60fps를 유지하고, 드래그를 놓았을 때 고해상도로 렌더링하도록 렌더링 패스를 분리하는 것을 권장합니다.
