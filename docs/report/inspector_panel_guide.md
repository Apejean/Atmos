# 스피커 인스펙터 패널 (Setup UI) 구현 가이드 (@Front 에이전트 용)

## 1. 아키텍처 개요 (Slide-in HUD Panel)
스피커를 탭하면 우측에서 좌측으로 부드럽게 밀려 나오는(Slide-in) 인스펙터 패널입니다.
전체적으로 어두운 반투명(Glassmorphism) 테마를 사용하여 뒤쪽의 3D 룸이 비치게 디자인합니다.

## 2. 우측 인스펙터 패널 (스피커 클릭 시 슬라이드 등장)
스피커를 탭하면 화면 우측에서 좌측으로 반투명(Glassmorphism) 패널이 스르륵 밀려 나옵니다. 내부는 위에서 아래로 다음과 같이 세로 배치(ListView) 됩니다.

**[상단 헤더 영역]**
*   **좌측 끝**: [X] 닫기 버튼
*   **우측 정렬**: Selected Speaker: [ CH 1 ▼ ] (채널 선택 드롭다운)

**[본문 영역: 7개의 제어 박스 (세로 나열)]**
각 박스는 좌측엔 직관적인 3D 아이콘, 우측엔 수치 입력칸(더블클릭 수정) 형태로 가로 분할되어 정갈하게 배치됩니다.
*   **Box 1**: `icon_x.svg` (좌우 이동) | [ X 좌표 값 ]
*   **Box 2**: `icon_y.svg` (앞뒤 이동) | [ Y 좌표 값 ]
*   **Box 3**: `icon_height.svg` (상하 높이) | [ Z 높이 값 ]
*   **Box 4**: `icon_pan.svg` (수평 회전) | [ 방위각 0~360° ]
*   **Box 5**: `icon_tilt.svg` (고개 숙임) | [ 숙임각 -90~90° ]
*   **Box 6**: `icon_dispersion.svg` (지향 빔) | [ 퍼짐 각도 & 도달 거리 ]
*   **Box 7**: `icon_reverb.svg` (룸 잔향) | [ Reverb Send & Early Ref ]

**[최하단 영역]**
위험을 알리는 붉은색 테두리의 **[ Remove Speaker (휴지통) ]** 버튼이 패널 맨 아래에 위치합니다.

## 4. 백엔드 동기화 (Rust FFI Sync)
*   사용자가 수치를 더블클릭하여 타이핑하거나 변경할 때마다 `_syncSpatialConfigRealtime()` 로직을 통해 즉각적으로 백엔드(Rust)로 데이터가 동기화되어야 합니다.
