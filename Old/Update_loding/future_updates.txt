# 향후 업데이트 대기 목록 (Future Updates Loading)

이 문서는 사용자가 나중에 최종적으로 업데이트할 때 한 번에 적용하기 위해 보류해둔 기능들의 목록입니다.
업데이트 지시가 떨어지면 아래의 기능들을 구현해야 합니다.

## 1. Windows 배포 및 권한 최적화 (사용자 요청 사항)
*   **Windows 부팅 시 자동 시작 (Auto-launch)**: 레지스트리(Run 키)를 활용하여 컴퓨터를 켜면 프로그램이 자동으로 백그라운드나 트레이에서 실행되도록 구현.
*   **인스톨러 제작 (Installer)**: Inno Setup 등을 활용하여 흩어진 exe와 dll 파일들을 사용자 친화적인 단일 설치 파일(`setup.exe`)로 묶는 작업.
*   **관리자 권한 강제 (Admin Privileges)**: `runner.exe.manifest` 수정을 통해 ASIO 장치 제어의 안정성을 위해 앱 실행 시 관리자 권한(UAC)을 강제로 요구하도록 설정.

## 2. 상용화 및 유지보수용 고급 기능 (에이전트 추천 사항)
*   **자동 업데이트 (Auto-Updater)**: 사용자가 매번 GitHub에서 압축 파일을 수동으로 다운로드할 필요 없이, 앱 실행 시 최신 버전을 감지하고 다운로드하여 패치하는 자동 업데이트 시스템 구축.
*   **로그/크래시 내보내기 (Crash Reporter)**: 현장에서 프로그램 다운 등의 이슈 발생 시, "오류 로그 내보내기" 버튼을 통해 분석용 `.txt` 파일을 쉽게 추출하여 개발자에게 전달할 수 있는 기능.
*   **라이선스 / 시리얼 키 (License Key 인증)**: 프로그램 상용 판매 혹은 특정 환경(B2B) 배포 시, 하드웨어 MAC 주소 기반이나 고유 시리얼 키 입력을 통한 인증 시스템 도입.
