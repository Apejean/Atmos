# 트랙 출력이 켠 그룹과 맞을 때만 소리(짧은 설계)

> 상태: **다시 채택(2026-11-22, `2026-11-22-output-config-separate-rows-design.md`).** 1.3.15·1.3.16 동안은 아래처럼 대체됐다가, 사용자가 "이전처럼 에이블톤처럼 따로 하자"를 골라 "종류가 맞아야 소리"로 돌아갔다. 다만 멀티 줄이 여는 채널은 장치 끝까지가 아니라 그 자리 트랙의 파일 채널 수만큼이다. 이전 상태: **대체됨(2026-11-21).** 같은 날 장치 확인 중 사용자가 "채널 하나로 묶기"를 골라 `2026-11-21-output-config-open-channels-design.md`로 바뀌었다. "화면에 안내가 뜨는 트랙은 무음"·트랙 카드 자동 변경 중지는 그대로이고, 맞는 기준이 "그룹 종류"에서 "열린 채널"로 바뀌었다(종류별 시작 채널 표는 만들지 않는다). 원래 상태: 사용자 결정 "A. 안내 뜨는 트랙은 무음", 설계 확인 "설계대로 구현", 트랙 카드 자동 변경은 "바꾸지 않고 주황 표시".

## 왜
"켠 그룹이 없으면 소리 없음" 빌드로 장치 확인 중(2026-11-21 15:21) 스테레오 CH1~2·CH23~24만 켜자, 24채널 LONG 루프(CH1 멀티 자리)는 트랙 카드에 주황 안내("Output Config에서 사용할 채널 그룹을 열어주세요")가 그대로인데 CH1~2·CH23~24로 소리가 났다. 엔진과 화면이 "소리를 내도 되는가"를 서로 다른 기준으로 본다:
- 엔진: **채널 하나하나**의 게이트(`compute_enabled_channels` → `GLOBAL_STATE.enabled_channels`). 열린 채널이면 어느 트랙이든 통과한다.
- 화면: **트랙과 그룹의 종류·시작 채널**(`buildChannelRoutingItems`). 다채널 파일은 멀티 그룹, 모노 파일은 모노 그룹, 스테레오 파일은 모노 또는 스테레오 그룹.
사용자가 A를 골랐다: 엔진이 화면 기준을 따른다 — 트랙 출력이 켠 그룹과 맞지 않으면(화면에 안내가 뜨는 트랙) 무음.

## 맞는 출력(화면 `buildChannelRoutingItems`와 같은 규칙)
트랙 출력 시작 채널 `c`(0부터, CH = c + 1), 그룹 키는 1부터(`c + 1`):
| 파일 채널 수 | 트랙 `output_stereo` | 맞는 조건 |
|---|---|---|
| 3 이상(다채널) | 상관없음 | 멀티 그룹 `c + 1`이 켜짐 |
| 1(모노) | 꺼짐 | 모노 그룹 `c + 1`이 켜짐 |
| 1(모노) | 켜짐 | 모노 그룹 `c + 1`이 켜짐 — 새 트랙 기본값이 "스테레오 출력 켬"이라, 화면은 모노 파일을 같은 채널의 모노로 보이고 트랙 카드가 표시만 모노로 고친다(채널은 그대로). 처음 구현은 "맞지 않음"이라 새로 넣은 모노 파일이 무음이 됐다(기존 시험 `test_mono_to_stereo_upmix`가 잡음) |
| 2(스테레오) | 꺼짐 | 모노 그룹 `c + 1`이 켜짐 |
| 2(스테레오) | 켜짐 | 스테레오 그룹 `c + 1`이 켜지고 `c + 1`번째 짝 채널이 장치 안 |
- 화면이 빼는 가상 채널(드라이버 내부 DAW 리턴 등)은 엔진이 모른다 — 화면에서 고를 수 없으므로 따지지 않는다.
- 채널 게이트는 그대로 둔다(맞는 트랙도 열린 채널로만 나간다).

## 엔진
- 그룹 종류별 "켜진 시작 채널" 표 세 개(`GLOBAL_STATE`의 원자형 배열, 모노·스테레오·멀티)를 `apply_enabled_channels`에서 게이트와 함께 채운다(오디오 스레드 밖).
- 믹서는 인스턴스마다 블록 한 번 위 표로 "맞는가"를 정하고(파일 채널 수는 인스턴스가 안다), 맞으면 1·아니면 0을 향해 출력 게인을 샘플 단위로 옮긴다(`OUTPUT_RAMP_S` 10ms, 3법칙 3 — 그룹을 켜고 끌 때 딸깍 없음). 할당·잠금 없음(3법칙 1·2).
- 맞지 않는 동안에도 재생 위치는 그대로 흐른다(루프는 나중에 그룹을 켜면 같은 위상에서 들린다). 재생 목록·OSC 응답은 바뀌지 않는다(재생 중이지만 무음 — 기존 1분 무음 경고가 뜬다).

## 화면(사용자 확인 필요)
트랙 카드는 지금 **저장된 출력이 목록에 없으면 목록의 첫 항목으로 몰래 바꾼다**(`track_card.dart`, 원래 옛 3D OBJECT 출력 4294967295를 옮기려던 것). 오늘 SHORT·ONESHOT이 사용자가 고르지 않은 CH25·26으로 옮겨진 원인이다. A에서는 이 자동 변경이 "출력이 맞지 않아 무음"을 가린다(그룹을 켜고 끄기만 해도 트랙 출력이 바뀐다). 권하는 것: 자동 변경은 옛 3D OBJECT 값에만 하고, 그 밖에는 저장된 출력을 그대로 두고 카드에 주황으로 "CH n (출력 설정에 없음)"을 보인다(환경설정 트랙 매핑의 "(Missing)"과 같은 뜻).

## 시험
- Rust: 맞는 조건 표(순수 함수)와, 믹서에서 맞지 않는 트랙은 출력이 0으로 줄고 위치는 흐르며 그룹을 켜면 같은 위치에서 다시 들리는 시험(게인이 한 번에 뛰지 않음).
- Dart: 트랙 카드가 목록에 없는 출력을 바꾸지 않는 시험(옛 3D OBJECT 값은 옮김).
- 장치: 스테레오 CH1~2·CH23~24만 켠 상태에서 LONG(멀티 자리) 무음, 멀티 CH1을 켜면 LONG 소리, SHORT(스테레오 파일)는 자기 자리 스테레오 그룹을 켜야 소리.
